How it works

  • Use the same column layout as the file produced by Export selected to Excel.
  • Rows with a matching Id column will update the existing record.
  • Rows with an empty Id will create a new record.
  • Empty cells are ignored on update (the existing value is kept) and use the field default on create.
  • For choice fields, you can use either the human-readable label (e.g. Color) or the raw value.
  • For foreign-key columns, you can use either the related record's ID or the same string the export wrote.
  • Image and file columns are skipped — URLs in the export aren't re-importable as files.
  • If any row fails validation, the whole import is rolled back — no partial saves.
