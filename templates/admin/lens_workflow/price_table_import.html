How it works

  1. Download the current prices, edit the file in Excel and keep the same layout (sheets Premium Lens and Economic Lens, one block per lens, a price or N in every cell).
  2. Upload it below. Check file only reports problems and changes nothing. Check and replace prices replaces the prices of every sheet in the file, but only when the file has no errors.
  3. A price means that lens exists for that power. N means it does not.
  4. Every uploaded file is kept in the history below, so an older version can be downloaded and uploaded again.
